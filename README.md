# Dimas HUB

Player de vídeo + lances do XML de tagueamento (Sportscode/Nacsport).
Clique no lance e o vídeo vai direto ao minuto.

- `index.html` — a página inteira (dados da partida embutidos).
- Fontes de vídeo: link do YouTube, link direto `.mp4` ou arquivo local.
- Para trocar a partida: botão **Carregar outro XML** na página.

Publicado via GitHub Pages.
